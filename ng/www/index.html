What is this?

This page is being served by a web server written entirely in LAML-NG — a minimal scripting language with checked arithmetic, first-class functions, and OS-thread concurrency. The TCP layer is handled by socat; the HTTP logic, file serving, and response generation are all pure LAML code.

How it works

socat TCP-LISTEN:8080,fork \
    EXEC:"./laml run server.lm"

Each HTTP connection forks a new process that runs the LAML interpreter. The request body is piped to stdin, and the HTTP response is written to stdout.
