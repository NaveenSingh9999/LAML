Changelog

v4.1.0 — Realtime language

  • Realtime servers: serve/on/send/broadcast/joinRoom/members, WebSocket (RFC6455) + HTTP/1.1 keep-alive + SSE on one port
  • Rooms & timers: sharded room bus, setTimeout/setInterval/cancelTimer, 54s heartbeat, 256KB per-connection backpressure (drop, don't OOM)
  • Dynamic DX: jsonParse/jsonStringify, async/waitFor, reload() hot-swaps handlers without dropping connections, stats() + /__stats
  • General stdlib: math (abs/min/max/floor/ceil/sqrt/pow/randInt), arrays (pop/remove/sort/reverse/join/slice), strings (upper/lower/replace/startsWith/endsWith/repeat), keys/has/string/fileExists/fileDelete/appendFile/assert
  • Core: float <=/>=/%, full mixed int/float comparisons, obj["key"] indexing, nil literal, closc :priority, thread-safe supervised concurrency
  • CLI: laml --help, laml --version, graceful SIGTERM drain
  • Measured: 7350/7350 WS fan-out delivered, 2000 idle WS at 13MB, 1000-connection churn +100KB — see ng/BENCH.md

v4.0.0 — C++20 runtime

  • Pure C++20 implementation, checked arithmetic, bounds-checked arrays
  • OS-thread closc system, dataflow scheduler
  • Core builtins: I/O, type introspection, file ops, strings, crypto, TCP/UDP
  • Error-as-values model with try()
