// Fibonacci benchmark
function fib(n) {
    if (n <= 1) return n
    return fib(n - 1) + fib(n - 2)
}

Enhanced Type System

LAML v4.0.0 introduces comprehensive data types with type inference and enhanced array support for safer, more expressive code.

// Type-aware programming
func processData(items) {
    let result = [];
    let count = 0;
    
    let item = 0;
    while item < len(items) {
        if items[item] > 10 {
            result.push(items[item]);
            count = count + 1;
        }
        item = item + 1;
    }
    
    return result;
}

First-Class Functions

Functions are first-class citizens with support for closures, higher-order functions, and functional programming patterns.

// Higher-order functions
function compose(f, g) {
    return (x) => f(g(x))
}

let addTwo = (x) => x + 2
let double = (x) => x * 2
let addTwoAndDouble = compose(double, addTwo)

Realtime Servers in 10 Lines (v4.1.0)

WebSocket, SSE, rooms, presence, timers and JSON are built in. One event loop + worker pool holds thousands of connections with sub-millisecond handlers and bounded per-connection queues.

~ 10-line chat relay
on("connect", func(fd, path) { joinRoom(fd, "lobby") })
on("message", func(fd, msg) { broadcast("lobby", msg, fd) })
on("close", func(fd) { leaveAll(fd) })
serve(8080, {ws: true, stats: true})

~ measured: 7350/7350 fan-out delivered,
~ 2000 idle WS at 13MB, slow clients dropped not OOMed
