Installation & Setup

Get LAML v4.0.0 installed on your system with the next-generation C++20 runtime:

Universal (Linux, macOS, Termux)

curl -fsSL https://github.com/NaveenSingh9999/LAML/raw/refs/heads/main/install.sh | bash

Clones source, installs dependencies, builds native binary, and installs it. Auto-detects your platform.

Tip

After installation, verify everything works by running laml --version in your terminal.

Key Control Flow Features

  • Nested If-Else: LAML uses nested structure instead of "else if"
  • Boolean Operators: Use && (AND), || (OR), ! (NOT) for complex conditions
  • While Loops: Condition-based iteration with increment/decrement
  • For Range Loops: for x in start to end { } for bounded iteration
  • Array Iteration: Manual indexing with bounds checking for arrays

Loop Best Practices

Remember that LAML uses while, loop, and for-range loops. Always ensure your loop conditions will eventually become false to avoid infinite loops!

Functions

Functions in LAML help organize code and enable reusability:

functions.lm 
// Function to calculate area of rectangle
func calculateArea(length, width) {
    let area = length * width;
    return area;
}

// Function to greet a person
func greet(name, age) {
    say "Hello, " + name + "! You are " + age + " years old.";
}

// Function to find maximum in array
func findMax(numbers) {
    let max = numbers[0];
    let i = 1;
    while i < len(numbers) {
        if numbers[i] > max {
            max = numbers[i];
        }
        i++;
    }
    return max;
}

let length = 5.5;
let width = 3.2;
let area = calculateArea(length, width);
say "Area: " + area;

greet("Alice", 25);

let scores = [85, 92, 78, 96, 88];
let highest = findMax(scores);
say "Highest score: " + highest;
Output: 
Area: 17.6
Hello, Alice! You are 25 years old.
Highest score: 96

Error Handling & Validation

LAML automatically validates that the number of format specifiers matches the number of arguments:

say("Hello %s %d", "World"); // Error: Missing argument for %d
say("Hello %s", "World", 42); // Error: Too many arguments

Best Practices

  • Precision Control: Use %.nf for precise float formatting
  • Type Safety: LAML automatically converts compatible types
  • Backward Compatibility: Old say "string" syntax still works
  • Escape Sequences: Work in both new and old syntax styles
  • Array Formatting: Arrays are automatically converted to readable strings

Real-world Example

Let's build a complete program that demonstrates multiple LAML v4.0.0 features:

student_grades.lm 
// Function to calculate average grade
func calculateAverage(grades) {
    let sum = 0.0;
    let count = 0;
    let i = 0;

    while i < len(grades) {
        sum = sum + grades[i];
        count = count + 1;
        i++;
    }

    return sum / count;
}

// Function to determine letter grade
func getLetterGrade(average) {
    if average >= 90.0 {
        return "A";
    } else {
        if average >= 80.0 {
            return "B";
        } else {
            if average >= 70.0 {
                return "C";
            } else {
                if average >= 60.0 {
                    return "D";
                } else {
                    return "F";
                }
            }
        }
    }
}

// Function to find highest and lowest grades
func findExtremes(grades) {
    let highest = grades[0];
    let lowest = grades[0];
    let i = 0;

    while i < len(grades) {
        if grades[i] > highest {
            highest = grades[i];
        }
        if grades[i] < lowest {
            lowest = grades[i];
        }
        i++;
    }

    return [highest, lowest];
}

// Student data
let studentName = "Alice Johnson";
let grades = [88, 92, 85, 90, 87, 94, 89];

say "Student Grade Report";
say "===================";
say "Student: " + studentName;
say "Grades: " + grades;

// Calculate statistics
let average = calculateAverage(grades);
let letterGrade = getLetterGrade(average);
let extremes = findExtremes(grades);
let highest = extremes[0];
let lowest = extremes[1];

// Display results
say "\nGrade Statistics:";
say "Average: " + average;
say "Letter Grade: " + letterGrade;
say "Highest Grade: " + highest;
say "Lowest Grade: " + lowest;

// Determine if passing
let isPassing = average >= 70.0;
if isPassing {
    say "\nStudent is passing!";
} else {
    say "\nStudent needs improvement.";
}
Output: 
Student Grade Report
===================
Student: Alice Johnson
Grades: [88, 92, 85, 90, 87, 94, 89]

Grade Statistics:
Average: 89.3
Letter Grade: B
Highest Grade: 94
Lowest Grade: 85

Student is passing!
